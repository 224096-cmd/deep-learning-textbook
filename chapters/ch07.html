RNN の記憶は毎回上書きされていました。LSTM（長・短期記憶、1997）は、上書きされない専用の記憶セル c と、 「どれだけ忘れるか」「どれだけ書き込むか」「どれだけ読み出すか」を 0〜1 で制御する 3 つのゲートを持ちます。 記憶セルへの足し算の道は、第4章の残差接続と同じ「勾配の高速道路」になります。

動画の対応箇所：25:52〜「Word Embeddings, RNN, LSTM and GRU」

f = σ(…) 忘却ゲート：前の記憶をどれだけ残すか（1=全部残す） i = σ(…) 入力ゲート：新しい情報をどれだけ書き込むか o = σ(…) 出力ゲート：記憶のうちどれだけ外に出すか g = tanh(…) 書き込み候補 c_t = f * c_{t-1} + i * g ← 掛け算と足し算だけ。f≈1 なら記憶がそのまま保たれる h_t = o * tanh(c_t)

体験①：ゲートを手で動かして「記憶」を観察する

1 次元の記憶セル c を使い、ゲートの値を自分で決めて入力を 1 つずつ流し込みます。

青＝記憶セル c の値、オレンジ＝出力 h。RNN と違い、「保つ」を何回押しても c は減りません。

体験②：勾配の流れを RNN と比べる

赤＝RNN、青＝LSTM（学習前、同じ乱数）。LSTM では記憶セルを通る道のおかげで、最初の時刻まで勾配が届きやすい。

体験③：学習レース RNN vs LSTM

同じ課題・同じ条件で、どちらが先に「解ける」か競争させます。T を長くすると差が開きます。

試してみよう：T=30 で LSTM は数百ステップで解けますが、RNN は 1000 ステップ以上かかるか解けないことが多いです。最適化を「SGD（素朴）」にすると、勾配消失の影響がより露骨に出ます。
