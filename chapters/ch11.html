Transformer（2017, "Attention Is All You Need"）は RNN を捨て、Attention だけで系列を処理します。 各単語が文中のすべての単語に注意を向ける自己注意（Self-Attention）を、見る観点の違う複数のヘッドで同時に行い、 RNN のように 1 語ずつ待たずに全単語を一度に（並列に）計算できます。順番の情報は位置エンコーディングで足します。

動画の対応箇所：47:30〜「Transformer, BERT and GPT」

// 1 つの Transformer ブロック X = 埋め込み + 位置エンコーディング Q = X·Wq, K = X·Wk, V = X·Wv （ヘッドごとに別の W） A = softmax( Q·Kᵀ / √d ) 全単語 × 全単語 の注意の表 X = X + A·V 残差接続（第4章） X = X + FFN(X) 各単語ごとの小さな MLP（第2章）

用語

  • 自己注意：Query も Key も Value も同じ文から作る Attention。文中の単語同士の関係を取り出す。
  • マルチヘッド：Attention を h 組並列に行う。ヘッドごとに「主語と動詞」「代名詞と指す先」など別の関係を見る。
  • 位置エンコーディング：単語の位置を表すベクトル。sin・cos の波を使うと、どんな長さでも作れる。
  • √d でのスケール：次元が大きいと内積が大きくなりすぎ softmax が尖るので、割って調整する。

体験①：マルチヘッド自己注意を計算する

行＝Query の単語、列＝Key の単語。各行の合計は 1。（重みは学習していない乱数なので、関係は「それらしい」とは限りません。構造を見るための実験です）

試してみよう：位置エンコーディングの✓を外して「単語順を入れ替える」と、各単語の行の中身（数値の集合）は入れ替わるだけで同じになります。 Attention 自体は語順を知らない（順番を入れ替えても同じ結果が並び替わるだけ）ので、位置の情報を別に足す必要があるのです。 ✓を入れて同じことをすると値そのものが変わります。

体験②：位置エンコーディング（sin・cos の波）

行＝位置、列＝次元。左の次元は速い波、右は遅い波。各行（位置）のパターンがすべて違うので、「何番目か」を区別できる。
