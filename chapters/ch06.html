この章で分かること

文章や音声のように順番に並んだデータ（系列）は、長さが決まっていません。 RNN（再帰型ニューラルネットワーク）は、同じニューロンを時刻ごとに繰り返し使い、前の時刻の「記憶」（隠れ状態）を次の時刻へ渡します。 ただし、記憶は毎回上書きされるので、遠い過去を覚えておくのが苦手です（勾配消失）。
// RNN の 1 ステップ（毎時刻、同じ W を使う） h_t = tanh( Wx·x_t + Wh·h_{t-1} + b ) // h_t = 「いままで読んだ内容の要約」（隠れ状態） // 最後の h_T から答えを出す
ことばの意味（タップで開閉）
  • 隠れ状態 h_t：時刻 t までに読んだ情報の要約ベクトル。RNN の「記憶」。
  • 展開（unroll）：ループを時間方向に引き延ばし、1 本の深いネットとして描くこと。深さ＝系列の長さ。
  • BPTT：展開したネットに対する誤差逆伝播。長い系列ほど「深い」ので、第4章と同じ勾配消失が起きる。

まず：RNN を時間方向に「展開」すると

左から右へ時刻が進む。同じ重み（同じ色のノード）を使い回しながら、隠れ状態 h が次の時刻へ渡される。青い光＝順伝播、赤い光＝BPTT（時間をさかのぼる逆伝播）。

体験①：隠れ状態が時間とともにどう変わるか

課題：「最初のビット（0 か 1）を、その後の雑音ビットが続いた最後まで覚えておき、最後に答える」。 下のビット列をクリックして変え、学習済み RNN の隠れ状態がどう変化するかを見ます。

未学習

縦＝隠れ状態の各次元、横＝時刻。赤＝正、青＝負。最初のビットの情報が、どの次元に「保存」されているか探してみましょう。

試してみよう：学習後、先頭ビットだけを 0↔1 に切り替えると、途中の雑音を変えても最後の予測が変わりますか？ 雑音ビットを変えると隠れ状態はどう揺れますか？

体験②：時間をさかのぼる勾配はどこまで届く？

最後の出力の誤差が、各時刻の隠れ状態にどれだけ届くか（対数軸）。左へ行くほど小さくなる＝最初の方の入力はほとんど学習の手がかりにならない。

体験③：どこまで長く覚えられるか（学習実験）

T を変えて RNN を学習させ、「解けるまでのステップ数」を記録しましょう。T が長くなると、どこかで解けなくなります。
